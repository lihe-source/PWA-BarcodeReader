# BarcodePro V3_1
發行日期：2026-10-26。基於 V3_0 更新；純靜態 PWA，部署於 GitHub Pages。
本版本沒有代為部署或修改遠端 GitHub。所有圖片辨識與歷史紀錄保存在本機，沒有帳號或雲端同步。

## 部署與更新
1. 在舊版「設定」先匯出 JSON，確認檔案已下載保存。
2. 解壓縮 PWA-BarcodeReader-V3_1.zip，進入同名資料夾。檔案均在這一層，沒有子資料夾。
3. 將這一層全部檔案一次上傳至 PWA-BarcodeReader 儲存庫的 Pages 發布根目錄，覆蓋同名檔案；不要把外層資料夾上傳成網站的子目錄。
4. 維持原來的網址 https://lihe-source.github.io/PWA-BarcodeReader/ 。使用不同來源、網址路徑或瀏覽器可能無法看到原資料。
5. 等待 Pages 發布完成，關閉其他 BarcodePro 分頁，停止相機，到「設定 → 檢查更新」。
6. 確認右上角及設定顯示 V3_1，且「核心離線資源完整」。再測試關閉網路後重新開啟。
首次安裝或尚未完成快取時需要連線。不可直接以 file:// 開啟 HTML 測試相機或 Service Worker。

## 本版完成項目
- 更新安全：掃描相機仍運作、資料寫入、圖片讀取／解碼、產碼載入、設定草稿或編輯視窗開啟時不套用更新。
- 每次啟動自動檢查、連線恢復及返回前景檢查；準備完成後於安全狀態自動套用。設定顯示當前／最新版本及手動檢查按鈕。
- 同一網站多視窗開啟時，提示關閉其他視窗後再啟用更新，避免另一頁被突襲切換版本。
- 更新資源 SHA-256 檢核：整套檔案符合發布清單才安裝；混合上傳失敗時不啟用新版。缺少的離線檔案重新下載時也驗證。
- 設定草稿：掃描規則、分類有未儲存提示及取消按鈕，不再以舊的頁面暫存覆蓋實際設定；切換音效不會清掉規則草稿。其他視窗設定變更會通知更新。
- 備份 schema 4：保留資料 ID、修改時間，讀取舊 schema 1–3。合併前顯示新增／相同／衝突數量，可選保留本機或使用備份內容。
- 還原前快照：成功還原交易會在本機保留最近一次還原前資料，可於設定匯出再還原。交易失敗不改變原資料。快照不是外部備份。
- V2 遷移失敗時保留原始資料並提示救援，設定可匯出原始 JSON 字串供修復。救援檔不等於一般可直接還原的備份。
- 歷史頁改為 createdAt 索引游標查詢，只保留當頁 30 筆畫面資料。隱藏時不因掃碼而重讀。搜尋與總數量統計仍須遍歷符合查詢的資料，不宣稱固定時間查詢。
- 連續掃描預設同碼需離開辨識框後才重新接受：連續五次未辨識到條碼視為離框。可於設定改回冷卻模式；此判斷無法識別同碼是否為另一個實體商品。
- 結果顯示已保存／未保存／失敗；「更多操作 → 數量＋1」原子性增加同筆已存紀錄的數量，不新增紀錄。
- 連續掃描維持相機高度；歷史列表收合完整內容與次要操作；底部分頁使用一致的 SVG 圖示；保留深色預設、淺色與系統主題。
- 圖片可拖曳框選與調整大小，保留滑桿作鍵盤操作。先裁切原圖再降採樣。提供快速第一碼與完整多輪搜尋；完整模式不保證找齊所有碼。
- 產碼套件按需載入、仍完整預先快取供離線使用；背景解碼失敗後最多嘗試兩次延遲重啟，保留主執行緒備援。
- CSV 數量欄為數值；讀值維持文字保護，以保留前導零及防止公式注入。原始內容完整交換請使用 JSON。
- 修正刪除通知的復原按鈕點擊，資料備份與危險清除操作分區。

## 相容與限制
- 仍使用 BarcodePro-v3 IndexedDB，正常升級不用清除網站資料，也不會自動刪掉 V2 原資料。
- V3_1 匯出的 schema 4 備份需用 V3_1 或更新支援版本還原；V3_0 不支援 schema 4。升級前保存舊版匯出的 JSON，供回退使用。
- 離線保存不代表永久保存：清除網站資料、瀏覽器回收、移除 App 等仍可能失去資料。請另存 JSON。
- 相機、燈光、縮放、音效及分享由裝置決定；iOS 不保證震動支援。辨識不佳可選圖片／裁切重試。
- 本版未加入帳號／雲端同步、盤點批次系統、分類封存管理、雙指縮放圖片或自動備份到外部雲端。
- 沒有執行真實瀏覽器、iPhone／iPad／Windows 相機、觸控、列印驗證；詳見 TEST-REPORT.md。

## 開發與檔案
部署不需要 npm 安裝或建置。zxing.min.js、bwip-js.min.js 為本機隨附函式庫，請保留授權檔。
主要檔案：index.html、styles.css、app.js、storage.js、scanner.js、importer.js、generator.js、history.js、decoder*.js、updater.js、service-worker.js、version.js、version.json、release-manifest.js、manifest.json 及 icons。

使用 Node.js 20+ 可執行：
```bash
node verify.cjs
node release.cjs V3_1_1
```
修改任何程式後都需使用新版本號執行 release.cjs，以重新產生版本、資源雜湊與 checksums.sha256，再一次發布全部檔案。不要手動修改雜湊或只上傳 version.json。
